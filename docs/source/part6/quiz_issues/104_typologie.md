### Question

Lequel n'est **pas** une des trois grandes familles de logiciels vues en cours ?

### Options (for single/multiple choice only)

Système d'exploitation
Logiciel machine (drivers)
Logiciel d'utilité
Logiciel financier

### Answer

3

### Tolerance (number type only)

_No response_

### Case Sensitive (text type only)

_No response_

### Explanation (optional)

Les trois familles sont : systèmes d'exploitation, logiciels machine (drivers) et logiciels d'utilité. « Logiciel financier » serait un logiciel d'utilité, pas une famille.
